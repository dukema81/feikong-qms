# 飞控QMS系统项目说明与操作手册

**版本**：V1.0 ｜ **面向**：质量管理人员、检验员、SQE、系统管理员

---

## 1. 系统简介

飞控QMS系统覆盖来料检验（IQC）、过程检验（IPQC）、成品/出货检验（FQC/OQC）、不合格品处置（NCR）、纠正预防（CAPA/8D）、SPC 过程能力、供应商质量、质量成本与开放集成，共 17 个功能页面。

## 2. 启动与登录

```bash
python backend/server.py          # 默认 http://127.0.0.1:8024
# 环境变量：FEIKONG_PORT 端口、FEIKONG_DB 数据库路径、PORT（容器模式绑 0.0.0.0）
```

## 3. 界面骨架

顶部标题栏（品牌/退出）→ 菜单栏（质量作业/质量工程/供应与成本/基础/系统）→ 左侧功能树（带待办角标）→ 中部工作区 → 右侧上下文栏 → 底部状态栏（待检/NCR/CAPA 实时计数）。

## 4. 逐页操作说明

| 页面 | 操作要点 |
| --- | --- |
| 质量驾驶舱 | 6 项 KPI、缺陷帕累托（柱+累计线）、SPC 控制图摘要、各类型合格率、状态分布 |
| 来料检验 IQC | 「新建检验单」选物料/供应商/批量 → 系统自动匹配方案载入项目并按 AQL 抽样；点行开详情 |
| 过程检验 IPQC | 须填工序；首件/巡检口径 |
| 成品/出货检验 | FQC 与 OQC |
| 检验单详情 | 按 seq 录 OK/NG（NG 填不良数与缺陷码）→ 保存录入 → 提交判定 → 判定（合格/不合格）→ 不合格自动开 NCR → 放行 → 关闭；右侧显示推进闸口通过状态 |
| 不合格品 NCR | 五态推进：评审（意见+处置方式）→ 下达处置（责任人+时限）→ 处置完成（结果）→ 验证关闭；让步接收超不良率上限会被拦截 |
| 纠正预防 CAPA | 发起 → 按 D1→D8 逐步推进，每步闸口提示缺失项；进度条实时显示 |
| 检验方案 | 查看方案与检验项目（A/B/C 等级标签） |
| 缺陷代码 | 按分类分组，A 致命/B 严重/C 轻微 |
| SPC 过程能力 | 控制图（UCL/CL/LCL/USL/LSL）+ Cp/Cpk 与能力等级 |
| 质量分析 | 帕累托、加权帕累托、FPY、月度趋势 |
| 供应商质量 | 月度评分表（IRR/PPM/三项分/等级）+ PPM 排行 |
| 质量成本 | PAF 四类占比条 + 明细 + 月度对比 |
| 质量文件 | SOP/SIP 版本受控清单 |
| 报表中心 | KPI 汇总 + 三类 CSV 导出 |
| 集成中心 | API Key（明文一次）/ Webhook（secret 一次）/ 字段映射 / 增量同步游标 |
| 系统设置 | 12 条业务规则（管理员可改）、账号管理、权限矩阵、系统信息 |
| 操作日志 | 全量审计（登录/推进/判定/配置变更） |

## 7. 常见问题

| 问题 | 处理 |
| --- | --- |
| 判定合格被拦截 | 存在致命缺陷（A类）→ 按规则必须判不合格并走 NCR |
| 提交判定置灰/报错 | 有检验项目未录入结果，或未登记缺陷代码 |
| 让步接收被拦截 | 不良率超过 concession_max（默认 3%），改为返工/挑选使用 |
| CAPA 推不了 | 按提示补齐：组长成员 / 描述≥20字 / 根因≥10字 / 效果验证 / 预防措施 |
| 新建检验单没有方案项目 | 该类型无启用方案时项目为空，可先在「检验方案」配置 |
| SPC 无数据 | 在 /api/spc/series POST 录入或由 IPQC 录入测量值 |
| 登录后立刻掉线 | 反向代理改写 Authorization 头，系统已支持 Cookie/查询串兜底 |
| 忘记 admin 密码 | 删除 backend/data/feikong.db 后重启（演示环境）或由其他管理员重置 |

## 8. 运维与备份

- 备份：复制 `backend/data/feikong.db`（WAL 模式，建议同时拷 -wal/-shm）。
- 重置演示数据：删除 db 文件后重启，启动时自动灌入确定性种子。
- 健康检查：`GET /api/health`；版本与路由数：`GET /api/version`。
- 部署：`PORT=8024 python backend/server.py` 即对外服务；也可用 deploy/build_package.py 产出的 tar.gz 离线部署。
