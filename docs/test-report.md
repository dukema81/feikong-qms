## 3. 覆盖矩阵

### 3.1 单元（39）

- 三套状态机顺序与禁止回退（检验七态 / NCR 五态 / 8D 八步）
- 检验闸口 6 项：批量、项目全录、致命一票否决、判定签署、仅合格放行、不合格关单须 NCR
- NCR 闸口 4 项：评审必填、让步不良率上限、处置责任人+时限、关闭须验证
- CAPA 闸口：D1 组队、D2 描述≥20字、D4 根因≥10字、D6 效果必填
- AQL：字码三水平、样本量 200（L 码）、Ac/Re 关系、AQL 越严 Ac 越小、判合格/不合格口径
- SPC：控制限有序、判异点检出、Cp/Cpk 良好过程、偏移过程 Cpk=min 口径、退化数据
- 口径：帕累托累计、缺陷加权 10/5/1、FPY 连乘、PPM、供应商评分与等级、IRR、COQ 失败占比、时限状态
- 权限：矩阵形状、admin 全量 / viewer 最小、检验员无 NCR 权

### 3.2 接口（24）

认证与错误口令 401、无令牌 401；角色隔离（检验员写 NCR/用户/设置 403，访客只读）；物料 CRUD 与重复 400；方案/缺陷主数据；**检验全链路**（创建→抽样 200→跳步拦截→开始→录入→跳步/无不良判不合格拦截→待判定→判定→放行→关闭）；**不合格自动开 NCR**；NCR 全链路闭环与让步超限 400；**CAPA 8D 七道闸口逐步推进至 D8 关闭**；SPC 60 点 + 新增录点；分析三接口；COQ 合法类别校验；供应商评分覆盖当月；幂等重放一致；多通道令牌（Bearer/查询串/X-Auth-Token）；API Key 鉴权与错误 Key 401；Webhook 清单与测试投递；映射与反查；CSV 导出（品牌文件名 + BOM 表头）；设置修改与审计日志；OpenAPI ≥40 path。

### 3.3 端到端（9）

17 页渲染零错误、驾驶舱 KPI、IQC 列表点击开详情弹层（含闸口侧栏）、NCR 种子多状态、CAPA 8D 进度条、SPC Cp/Cpk 展示、设置页新建账号生效、集成四 Tab 切换、登录错误提示。

## 4. 缺陷台账（8 项，全部闭环）

| # | 现象 | 根因 | 修复 |
| --- | --- | --- | --- |
| 1 | /api/board 500 | sqlite3.Row 无 .values() | 改 r[0] 取值 |
| 2 | 检验单 CSV 接口 500 | return 缺右括号 | 语法修复 |
| 3 | 测试库登录失败 | server 启动未灌种子 | main() 空库自动 seed |
| 4 | 全量跑 database is locked 级联 | 异常路径连接泄漏持锁 | db.py 线程本地登记 + 请求结束兜底关闭（close_thread_conns） |
| 5 | OpenAPI paths=0 | 路由正则 ^/$ 锚点未剥 | strip("^$") |
| 6 | 驾驶舱 SPC 图 NaN | 传入数字数组而非对象 | 前端 map 包装 {value} |
| 7 | 放行报「仅合格单可放行」 | 闸口 verdict 未回落单据值 | `m.get("verdict") or r["verdict"]` |
| 8 | 供应商重复评分 500 | (month,supplier) 唯一键冲突 | INSERT OR REPLACE |

另：SPC 种子离散度过大致 Cpk=0.56（种子修正为 ±0.2 带宽 → Cpk≈1.26~1.35）；供应商评分种子公式过低致无 A 级（改为按等级基准分）；DEMO 快照 `{list}` 包装未解包；DEMO 同 hash 不重渲染属框架既定行为（冒烟绕行）。
